# External references

These are references, **not dependencies**. They are intentionally not Git submodules in the initial repository.

- OpenAladdin — https://github.com/tritao/OpenAlladin
  - workflow frontend, deterministic trace/compare model, pinned Ghidra/PyGhidra setup
- Quicky — https://github.com/tritao/quicky
  - provenance, evidence discipline, controlled experiments, handoff documentation
- PARTYMOD THPS2 — https://github.com/PARTYMANX/partymod-thps2
  - existing THPS2 PC patching/rendering research; useful for cross-checking later
- thps2-tools — https://github.com/JayFoxRox/thps2-tools
  - THPS2/Neversoft file-format research

If we later need to build directly against an external source tree, add it deliberately and pin a commit. Do not make a research reference a submodule merely for convenience.
